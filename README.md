

| Tytuł projektu: | System Inwentaryzacji Żetonów |
| :---- | :---- |
| Zespół: | [Dawid Bogacki](https://gitlab.com/Gegrod) (180578), [Igor Kamiński](https://gitlab.com/ikaminski) (180594), Grupa 1 |
| Idea i problem: | Kontrolowanie przepływu żetonów jest czasochłonne. Liczenie ich ręczne jest żmudne, a próba dojścia do wniosków na podstawie historii transakcji uciążliwa i czasochłonna. Dzięki Systemowi Inwentaryzacji Żetonów można automatycznie logować przepływ żetonów w magazynie i innych automatach, utrzymywać pieczę nad dokładną ilością poszczególnych nominałów oraz otrzymywać powiadomienia, gdy wymagane jest uzupełnienie. |
| Użytkownicy i scenariusz: | Główną grupą odbiorców są kasyna i ich pracownicy. Użytkownik używa aplikacji do wykonywania i monitorowania transakcji żetonów w kasynie. Uzyskuje wgląd do ilości dostępnych żetonów z podziałem na nominały w magazynie oraz automatach na sali oraz historii transakcji. |
| Zakres funkcjonalny: |  **ID Funkcjonalność Zakres** F01 Użytkownik ma wgląd do ilości żetonów w magazynie MVP F02 Użytkownik może wprowadzać zmiany ilości żetonów w magazynie po fizycznym ich wyjęciu. MVP F03 Użytkownik ma wgląd do chronologicznej historii transakcji. MVP F04 System informuje użytkownika o małej oraz krytycznej ilości żetonów w magazynie i/lub automatach. MVP F05 Walidacja nie pozwala wprowadzenie niepoprawnych danych. MVP F06 System automatycznie aktualizuje historię transakcji po dokonanych zmianach. MVP  |
| Poza zakresem: | Obsługa wielu automatów Dynamiczne dostosowywanie istniejących nominałów |
| Organizacja współpracy: | Separacja Frontend/Backend, ze zrozumieniem tego że okazjonalnie problemy mogą nas przerosnąć, więc w porządku jest prosić o pomoc. |
